# 📊 주식 시장 예측 시스템 - 상세 설명서

## 🎯 전체 시스템 개요

이 프로젝트는 **딥러닝(AutoEncoder + LSTM)을 활용한 주식 가격 예측 시스템**입니다.

### 핵심 목표
- 과거 주가 데이터와 재무 지표를 학습하여 미래 주가를 예측
- AutoEncoder로 고차원 데이터를 압축하고, LSTM으로 시계열 패턴 학습
- 20일 후의 주가 변동률(수익률)을 예측

### 4. **models.py** - 딥러닝 모델 정의

#### 4-1. AutoEncoderLSTM 함수
**역할:** 차원 축소 모델

```python
입력: (시간스텝, 특징 개수)
  ↓
LSTM(1024) - 인코더 1층
  ↓
LSTM(256) - 인코더 2층 (압축된 표현)
  ↓
LSTM(1024) - 디코더 1층
  ↓
LSTM(특징 개수) - 디코더 2층
  ↓
출력: 원본과 동일한 형태로 복원
```

**목적:**
- 수백 개의 특징을 256차원으로 압축
- 중요한 정보만 추출
- 노이즈 제거

#### 4-2. ResLSTM2noise 함수
**역할:** 실제 예측 모델

```python
입력: 압축된 데이터 (시간스텝, 256)
  ↓
LSTM(800) - 1층
  ↓
LSTM(800) - 2층
  ↓
LSTM(800) - 3층
  ↓
Dense(1) - 각 시간스텝마다 예측값 출력
  ↓
출력: 수익률 예측 (시간스텝, 1)
```

#### 4-3. training 함수
**역할:** 모델 학습

```python
for iteration in range(n_iteration):
    1. 배치 데이터 추출
    2. AutoEncoder로 인코딩 (선택적)
    3. 예측 모델로 forward pass
    4. 손실 계산 (MSE)
    5. Gradient 계산
    6. 가중치 업데이트
    7. 100번마다 성능 출력
```

### 5. **systems.py** - 학습 시스템

#### 5-1. MarketPrediction 클래스 (부모 클래스)
**공통 기능:**
- `data_load()`: 데이터 로드
- `preprocessing()`: 전처리
- `evaluation()`: 평가 및 결과 저장

#### 5-2. AutoEncoderLSTM 클래스 (자식 클래스)
**핵심 메서드: moving_transfer_learning()**

```python
전체 과정:
1. 전체 데이터를 train/test로 나눔
2. test 구간을 20일씩 이동하며 학습-예측 반복

예시 (train_period=500, test_period=20):
┌─────────────────────────────┐
│ 이동 1                       │
├─────────────────────────────┤
│ Train: 0~500일              │
│ Test: 500~520일             │
└─────────────────────────────┘

┌─────────────────────────────┐
│ 이동 2                       │
├─────────────────────────────┤
│ Train: 20~520일             │
│ Test: 520~540일             │
└─────────────────────────────┘

... 반복 ...
```

**각 이동마다:**
1. **AutoEncoder 학습** (1000 또는 500 iteration)
   - 입력 데이터를 압축 후 복원하도록 학습
   
2. **Encoder 추출**
   - 학습된 AutoEncoder에서 인코더 부분만 분리
   
3. **예측 모델 학습**
   - 압축된 데이터로 수익률 예측하도록 학습
   
4. **예측값 생성**
   - Test 데이터를 인코딩 후 예측

## 💡 핵심 알고리즘 설명

### AutoEncoder + LSTM 구조

```
[원본 데이터]
    ↓
[AutoEncoder - 압축]
    ├─ 수백 개 특징 → 256차원
    └─ 노이즈 제거, 핵심 정보 추출
    ↓
[LSTM - 시계열 학습]
    ├─ 60일간의 패턴 학습
    └─ 20일 후 수익률 예측
    ↓
[예측 결과]
    ├─ 수익률 → 가격 변환
    └─ 평가 지표 계산
```

### Moving Window Transfer Learning

```
기존 방법: 전체 데이터를 한 번에 train/test 분리
문제점: 시간이 지나면 모델 성능 저하

이 프로젝트의 방법:
- 20일마다 모델 재학습
- 최신 500일 데이터만 사용
- 실제 거래 환경 시뮬레이션
```

## 📊 평가 지표 설명

### 1. MSE (Mean Squared Error)
```
예측 수익률과 실제 수익률의 차이 제곱 평균
낮을수록 좋음
```

### 2. MAPE (Mean Absolute Percentage Error)
```
예측 가격과 실제 가격의 절대 오차율 평균
낮을수록 좋음
```

### 3. Accuracy
```
상승/하락 방향 예측 정확도
높을수록 좋음
```

### 4. PDA (Price Direction Accuracy)
```
예측한 방향과 실제 방향이 일치하는 비율
높을수록 좋음
```

### 5. PRCR (Price Recovery Correct Rate)
```
예측 오차가 30%, 50%, 70% 이내인 비율
높을수록 좋음
```

## 🎓 예시로 보는 동작 과정

### 예시 데이터:
```
날짜        수정주가    거래량    PER    ...
2023-01-01  50000      1000     15     ...
2023-01-02  51000      1100     15.2   ...
2023-01-03  50500      900      15.1   ...
...
2023-03-02  55000      1200     16     ...  (60일째)
...
2023-03-22  57000      1300     16.5   ...  (80일째, 60+20)
```

### 학습 과정:
```
1. 입력 생성:
   - 60일 데이터: 2023-01-01 ~ 2023-03-02
   - 정규화: 각 특징마다 평균0, 표준편차1

2. Target 생성:
   - 2023-03-02 가격: 55000원
   - 2023-03-22 가격: 57000원
   - 수익률 = (57000 - 55000) / 55000 * 100 = 3.64%

3. AutoEncoder:
   - 입력: (60일, 300개 특징)
   - 압축: (60일, 256차원)

4. LSTM 예측:
   - 압축된 데이터로 학습
   - 예측: 3.5% (실제: 3.64%)

5. 평가:
   - MSE = (3.5 - 3.64)^2 = 0.0196
   - 방향: 둘 다 상승 → 정확!
```
